# 硬过滤规则与综合评分

## 0. 过滤模式（重要）

analyze.py 支持两种硬过滤模式：

| 模式 | 触发方式 | 对真实开奖历史通过率 | 说明 |
| --- | --- | --- | --- |
| **数据驱动校准（默认）** | 默认 | 约 66%~85% | 和值/跨度取历史 5%~95% 分位；AC 取覆盖 90% 期数的最小连续区间；奇偶/大小/三区取累计覆盖 85% 的形态集合 |
| 固定阈值 | `--fixed-filter` | 约 7%（DLT 实测） | 下文第 1 节的原文档阈值，仅作对照或用户明确要求时使用 |

**为什么默认校准**：回测显示原文档固定阈值会把约 93% 的真实开奖形态滤掉——过滤器越严并不提高命中，只是把推荐集中到"历史多数形态"，同时系统性排除真实会开出的冷门形态。校准模式在"过滤明显极端形态"与"不过度排除真实开奖"之间取平衡。JSON 输出的 `硬过滤` 字段包含两种模式的通过率对照，报告中须呈现。

## 1. 固定阈值硬过滤规则（`--fixed-filter` 模式）

### 1.1 大乐透硬过滤

**前区**：
- AC ∈ 6-9
- 和值 ∈ 85-115
- 跨度 ∈ 18-28
- 奇偶比为 3:2 或 2:3
- 大小比为 3:2 或 2:3
- 三区比为 2:2:1 或 1:2:2 或 2:1:2
- 连号组数 ≤ 2
- 同尾个数 ≤ 2
- 与上期重号 0-2 个

**后区**：
- 2 个不重复号码，范围 01-12
- 至少 1 个热号或中温号

### 1.2 双色球硬过滤

**红球**：
- AC ∈ 7-10
- 和值 ∈ 80-130（优先 90-120）
- 跨度 ∈ 16-30
- 奇偶比为 3:3 或 4:2 或 2:4
- 大小比为 3:3 或 4:2 或 2:4
- 三区比为 2:2:2 或 3:2:1 或 2:3:1 或 1:2:3 或 2:1:3
- 连号组数 ≤ 2
- 同尾个数 ≤ 3
- 与上期重号 0-2 个

**蓝球**：
- 1 个，范围 01-16
- 优先综合分 Top 蓝球，可附 1-2 个冷号回补备选

## 2. 综合评分

```
Score = 0.73 × Base_14 + 0.27 × Advanced_11
```

归一化到 0-100。

**流程**：
1. 计算主区单号得分、副区单号得分
2. 生成候选池
   - DLT：前区 Top15-20，后区 Top6
   - SSQ：红球 Top18-24，蓝球 Top5-8
3. 生成候选组合并硬过滤
4. 组合分 = 主区均分 + 副区分 + 形态匹配 + 蒙特卡洛频次 + 逆向/爆冷加成
5. Score ≥ 75 进入推荐池
6. 输出 5-10 注，按综合分降序

## 3. 真实实现

本节逻辑已全部实现为可执行 Python 脚本，分析时直接运行，不再使用伪代码：

- `scripts/fetch_data.py`：拉取最新历史数据（官方接口 + 备用源，增量更新，自动校验与去重）
- `scripts/analyze.py`：完整分析引擎——本文件所有硬过滤规则（`hard_filter_main`）、阈值校准（`calibrate_params`）、评分流程（`build_recommendations`）、复式（`build_multi_groups`）、胆拖（`build_dantuo`）及 14 维指标与 11 项模型
- `scripts/backtest.py`：滚动回测——评分模型 vs 随机基线的覆盖能力、硬过滤对真实开奖的拦截率
- `scripts/check.py`：对奖工具——核对投注号码与开奖结果，输出中奖等级与参考奖金

如需调整固定阈值，修改 `analyze.py` 顶部的 `PARAMS` 字典即可，两彩种参数相互独立。

## 4. 模型改进说明（相对原文档）

| 项 | 原文档做法 | 现实现 | 理由 |
| --- | --- | --- | --- |
| 冷热判定 | μ±σ 正态近似 | 威尔逊置信区间 | 100-200 期小样本下正态近似偏差大，威尔逊区间更稳健 |
| 马尔可夫 | 等权转移计数 | 指数时间衰减（半衰期 30 期） | 近期转移模式权重更高，符合原文档"近 30 期可提高权重"意图 |
| 蒙特卡洛输出 | 裸频次 | 入选率 + 95% 威尔逊置信区间 | 呈现估计不确定性，避免把模拟噪声当信号 |
| 硬过滤 | 固定阈值 | 数据驱动校准（默认） | 固定阈值对真实开奖通过率仅 7%，见第 0 节 |

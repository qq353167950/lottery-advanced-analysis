# 高级11项数学模型（权重合计 27）

## 6.1 马尔可夫链（权重 5）

**状态定义**：
- 主区：三区 / 奇偶 / 大小
- 副区：DLT 后区 01-12；SSQ 蓝球 01-16；或分组

**一步转移概率**：

```
P_ij = f_ij / sum_k(f_ik)
```

可选拉普拉斯平滑：

```
P_ij = (f_ij + K) / (sum_k(f_ik) + K*m)
```

**k 步转移**：`P^(k) = P^k`

**加权预测**：

```
P_hat_j = sum_{k=1..K} W_k * P^(k)[s_{t-k}, j]
W_k = |R_k| / sum(|R|)
```

默认 K=5，近 30 期可提高权重。

**输出**：主区区间/号码 Top，副区号码 Top。

## 6.2 贝叶斯概率（权重 4）

**先验**：DLT 主区 5/35；SSQ 红球 6/33，蓝球 1/16

**似然**：

```
L_i = (n_i + α) / (N + α*m)
```

按后验排序，优先高后验号码。

## 6.3 遗漏模型（权重 4）

**遗漏强度**：

```
S_i = (O_i / O_avg) * (1 - exp(-O_i / O_max))
```

**回补近似概率**：
- DLT：`1 - (1 - 1/35)^O`
- SSQ 红：`1 - (1 - 1/33)^O`
- SSQ 蓝：`1 - (1 - 1/16)^O`

**判断规则**：
- S_i > 1.5 → 超冷回补信号
- 当前遗漏 ≥ O_max 的 70% → 强信号

## 6.4 AC 值模型（权重 3）

- DLT 得分：AC ∈ 6-9 → 1.0；AC = 5 或 10 → 0.6；其他 → 0.2
- SSQ 得分：AC ∈ 7-10 → 1.0；AC = 6 或 11 → 0.6；其他 → 0.2

## 6.5 奇偶模型（权重 3）

- DLT：主推 3:2 / 2:3；避免 5:0 / 0:5
- SSQ：主推 3:3 / 4:2 / 2:4；避免 6:0 / 0:6
- 可叠加奇偶状态马尔可夫链

## 6.6 区间模型（权重 3）

- 使用对应彩种三区定义与主形态（见 parameters.md）
- 断区连续 0 出 → 回补概率上升
- 可与三区马尔可夫联动

## 6.7 蒙特卡洛模拟（权重 4）

- 模拟次数 N = 100,000 ~ 1,000,000
- 采样权重正比于：后验 × 遗漏强度 × 转移概率
- 输出：号码频率排名、组合频次、验证推荐强度

## 6.8 组合优选（权重 3）

**目标函数**：

```
F = w1*Score_base + w2*Score_adv - λ*Overlap
```

- 生成方式：主区 Top 池 × 副区 Top 池 → 贪心/抽样/遗传算法优选
- 结果必须通过硬过滤（见 scoring-filter.md）

## 6.9 逆向形态捕捉（权重 2）

捕捉低频偏态且可能回补的形态：

1. 尾数高度集中
2. 稀缺多连号（三连/四连）
3. 断区/偏区极端
4. 零重号
5. 和值/跨度极端后回归

**触发条件**：该形态当前遗漏 ≥ 1.8 × 历史平均遗漏

**输出**：与主流推荐互补的逆向组合。

## 6.10 爆冷结构识别（权重 2）

**特征**：
- 冷号数量 ≥ 3（O > 1.5 × O_avg）
- 冷热搭配极端
- 和值或跨度偏离主区间
- 副区极冷

**评分**：

```
BurstScore = sum(S_i for i in Cold) + I(extreme_ratio) + I(sub_extreme)
```

**高分策略**：冷号主导 + 1-2 个热号平衡 + 副区对冲。

## 6.11 副区专项模型（权重 3）

### A. 大乐透后区连号模型

- 连号定义：|b1-b2| = 1，历史占比约 15%-20%
- 主流形态：差值 ≥ 2
- 差值高频区：1, 2, 3, 4, 5, 6
- 冷热搭配：1热1温 / 1热1冷 / 双温
- 奇偶、大小、除3余数：跨组优先
- **主推**：跨组 + 1热1温
- **辅推**：连号遗漏高时推连号
- **避免**：双极冷 + 同组

### B. 双色球蓝球专项模型

- 蓝球为单码，不做双号连号
- 冷热定义：热 = 近 30 期高频；冷 = 长遗漏近最大；温 = 中间层
- 振幅：|本期蓝 - 上期蓝|，统计历史振幅分布预测下期区间
- 邻号：上期蓝 ±1、±2 的历史命中率
- 马尔可夫：状态 = 01-16，或奇偶/大小/除3余数
- **主推**：高后验 + 热/温 + 合理振幅
- **辅推**：超冷回补 1 码
- **避免**：只追单一热号、忽略振幅与遗漏

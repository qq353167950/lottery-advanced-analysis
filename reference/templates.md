# 输出报告模板

**核心规则：分析在前，号码在最后。推荐号码必须以独立代码块收尾，方便整块复制。**

## 1. 大乐透模板

````
【大乐透 高级综合分析报告】
数据范围：第XXXX期 ~ 第XXXX期（共 N 期）
数据来源：[体彩官方接口/500.com/用户提供]，本次新增 X 期
上期开奖：前区 XX XX XX XX XX + 后区 XX XX

一、基础14维摘要
（热号/冷号/遗漏/近期形态等）

二、高级模型结果
1. 马尔可夫转移Top
2. 贝叶斯后验Top
3. 遗漏回补强信号
4. 蒙特卡洛频率排名
5. 逆向形态与爆冷结构
6. 后区连号/冷热推荐

三、关键规律总结 + 下期观察重点

四、推荐组合（N注，按综合分排序）
每注附：综合分/和值/跨度/AC/奇偶/大小/三区/重号（来自JSON，不得改动）

—— 推荐号码（复制即用）——
```
03 08 18 22 29 + 02 05
07 09 15 24 33 + 03 11
...
```
````

## 2. 双色球模板

````

数据范围：第XXXX期 ~ 第XXXX期（共 N 期）
数据来源：[福彩官方接口/500.com/用户提供]，本次新增 X 期
上期开奖：红球 XX XX XX XX XX XX + 蓝球 XX

一、基础14维摘要

二、高级模型结果
1. 马尔可夫转移Top（红球区间+蓝球）
2. 贝叶斯后验Top
3. 遗漏回补强信号
4. 蒙特卡洛频率排名

```
````

## 3. 复式模板（用户指定复式时使用，替代单式报告的第四节）

**复式模式下报告不包含单式推荐组合**，第四节直接为复式推荐：

````
四、复式推荐（M+S，共 N 组）
组1：等效注数 XXX 注；投注金额 XXX 元（2元/注）
     三区分布 X:X:X；奇偶 X:X；含上期重号 X 个
（多组时逐组列出，组间号码已自动差异化）

—— 复式号码（复制即用）——
```
03 07 08 15 18 22 29 33 + 02 05 11
```
````

## 4. 胆拖模板（用户指定胆拖时使用，替代单式报告的第四节）

````
四、胆拖推荐（主区D胆T拖 + 副区S）
等效注数 XXX 注；投注金额 XXX 元（2元/注）
胆码三区分布 X:X:X；胆码含上期重号 X 个
说明：胆码必出，从拖码中任选(选号数-胆数)个组成一注

—— 胆拖号码（复制即用）——
```
胆 08 18 拖 11 13 16 22 24 34 + 02 05 08
```
````

## 5. 硬过滤透明度（每份报告必含）

在"一、基础14维摘要"之后加入一段：

```
硬过滤模式：数据驱动校准（对历史真实开奖通过率 XX%；原固定阈值仅 XX%）
生效阈值：和值 XX-XX；跨度 XX-XX；AC X-X；奇偶/大小/三区形态 X 种
```

数据取自 JSON 的 `硬过滤` 字段。

## 6. 上次推荐结算播报（JSON 含 `上次推荐结算` 时必含）

在报告开头"数据说明"部分加入：

```
上次推荐结算（第XXXX期已开奖）：
开奖号码：XX XX XX XX XX + XX XX
推荐命中：注1 中X+X（XX奖/未中奖）…
固定奖合计：XX 元
累计战绩：已结算 X 次，投入 XXX 元，固定奖回收 XX 元（回报率 X.XX，随机基线约 0.27）
```

数据取自 JSON 的 `上次推荐结算` 与 `账本.累计统计` 字段。

## 7. 模板使用要求

1. "数据范围 + 数据来源 + 新增期数"为强制内容，证明分析基于最新数据
2. **推荐号码代码块必须是整个输出的最后一个元素**
3. 复式/胆拖模式下只输出对应号码代码块，不得出现单式推荐
4. 号码文本直接取自 analyze.py JSON 输出的 `号码文本` 字段，禁止手工改写或重排
5. 所有数值必须来自脚本计算结果，禁止手工估算填充
6. 双彩种分析时，两份报告分别独立输出，不合并
7. 向用户描述模型价值时定位为"形态筛选与资金结构管理"，不得暗示提高中奖概率（回测已证明覆盖能力与随机无显著差异）；账本统计仅用于诚实对照，不得作为"模型有效"的证据
